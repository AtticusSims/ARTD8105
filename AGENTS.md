# ARTD8105 — agent instructions

These instructions apply to student coursework throughout this repository.
For instructor maintenance of the shared class repository, do not create student
coursework logs from the maintenance conversation.

Read `.cursor/rules/00-course.mdc` for course conventions and
`.cursor/rules/10-research-log.mdc` for the logging workflow. Follow
`context/provenance_logging_spec.md` for record formats.

## Logging is automatic

Start or resume the research log without waiting for a student to request it.
Record every substantive exchange before finishing your response, and record the
student's response to earlier output when it becomes visible. This applies to
coding, reading, research, design, critique, debugging and repository work.

Use `my_work/_research_log/`. Keep a distinct session file for each working
session; never reuse another chat's file merely because it is the newest. Preserve
existing records, append corrections, and mark all late reconstruction explicitly.
If the workbook step is unclear, use `NA` rather than delaying the log or guessing.

Inspect the file after writing. Never say work was logged unless the record is on
disk. If file access or the required context is unavailable, explain the gap.
Do not invent past timestamps, decisions, reasons, citations or student sign-off.

Student work belongs in `my_work/`; shared course instructions stay unchanged in
student copies. Preserve unrelated edits and inspect changes before committing.
Push to the student's own remote only when requested; never push student work to
the shared course remote.
