## 6 · How to use this file with the agent

```
@venue/<slug>.md

Score my [section] against the derived standard in the venue file. Name each
criterion you apply and quote the file. Where the file is silent, say so
rather than filling the gap from general impressions.
```

If the agent replies with something like *"this is a strong introduction that
clearly conveys your contribution,"* it has ignored the file. Ask it again and
require criteria and quotations.
