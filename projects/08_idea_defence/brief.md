## Record your reviews

1. Get the latest course files in Cursor. Open `review.html` in Chrome or Edge.
2. Enter your name. Complete the presenter names, project title and three feedback fields. **Save & next** stores the review and opens a blank form. Select a previous review to edit it.
3. Use **Save review file** to save `idea_defence_reviews.json` inside your own `my_work/peer_reviews/` folder. Once connected, the file updates after each completed review. Other browsers can download a copy; move the latest copy into that folder.
4. **Commit and push the review file to your own GitHub repository before leaving. Your work counts only after it is pushed.** Save and push again after later edits.

Write specific feedback in English or Chinese. Do not review your own presentation.
